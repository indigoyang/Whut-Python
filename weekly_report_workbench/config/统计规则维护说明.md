# 统计规则维护说明

网站中的“统计规则设置”用于修改常见筛选口径。保存后规则会写入
`config/report_rules.json`，之后团队成员生成的报告默认使用最新规则。

可配置内容：

- 注册、订单、Google、Bing 的字段对应关系；
- 新用户判断字段和值；
- 续费来源值；
- KOL、Affiliate 合作渠道前缀；
- 合作渠道为空时的末次来源归类；
- Google 消耗排除关键词；
- 英语、繁中、北美地区国家范围。

修改前后应各生成一份同周期报告核对。新增指标、修改 Excel 结构或增加新的
跨表计算仍需修改 Python。规则文件的 Git 历史可用于查看和恢复旧版本。
