# 月度目标维护

每个月月初只需要在 `monthly_targets.json` 中新增或修改当月配置，之后本月生成的周报都会复用同一份目标。

配置格式：

```json
{
  "2026-11": {
    "all_channel": {
      "新增注册": 100000,
      "新用户总收入": 80000
    },
    "sem": {
      "总消耗": 50000,
      "SEM新用户总收入": 60000
    }
  }
}
```

- `all_channel`：全渠道周报的目标。
- `sem`：SEM 周报的目标。
- 指标名必须与报表第一列完全一致。
- 金额、人数等指标直接填写目标数值。
- 百分比目标填写百分数，例如目标 ROI 为 75%，填写 `75`。
- 未配置目标的指标显示 `-`。
- 完成率统一按 `MTD ÷ 目标` 计算，并保留整数百分比。
